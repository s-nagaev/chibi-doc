# Chibi Documentation (Mintlify)

This directory contains the complete, modular documentation for Chibi, optimized for [Mintlify](https://mintlify.com).

## Structure

- `mint.json`: The configuration file for Mintlify, defining navigation and styling.
- `introduction.md`: The landing page.
- `quickstart.md`: The 5-minute setup guide.
- `installation/`: Detailed installation methods.
- `configuration/`: Modular configuration reference.
- `guides/`: Task-focused tutorials.
- `agent-mode/`: Advanced agent capabilities documentation.
- `support/`: Troubleshooting and FAQ.
- `changelog.md`: Version history.

## How to Preview

1. Install the Mintlify CLI: `npm i -g mintlify`
2. Run `mintlify dev` in the root of the repository.
3. Open `http://localhost:3000` in your browser.
